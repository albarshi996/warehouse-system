# تشغيلُ المحوَّل الهجين — خطوةً خطوة

> **لمن؟** للمالك وحدَه. · **متى؟** حين تقرّر أن تُجرّب.
> **القاعدةُ الحاكمة:** لا خطوةَ هنا تُغيّر البوّابةَ على الناس إلّا الأخيرة —
> وكلُّ ما قبلها يُجرَّب ويُرجَع عنه بلا أثر.

---

## ٠ · ما يتغيّر وما لا يتغيّر

| | |
|---|---|
| **اليوم** | البوّابةُ تقرأ وتكتب في Firebase. المرآةُ تعمل في الخلف ولا أحدَ يقرؤها |
| **بعد المرحلة ١** | المرآةُ تصير **كاملةً** (٩٨ مجموعة بدل ٥). البوّابةُ لا تتغيّر حرفًا |
| **بعد المرحلة ٣** | الأصنافُ والمستنداتُ **تُقرأ من جهازك**. وكلُّ ما سواها من Firebase |
| **في كلّ الأحوال** | **الكتابةُ كلُّها تبقى في Firebase** — فلا شيءَ يُفسَد بنيويًّا |

★ **والسقوطُ الآمن:** إن نام جهازُك أو انقطع، ترجع القراءةُ إلى Firebase
تلقائيًّا في أقلَّ من ثانية. البوّابةُ تبطُؤ قليلًا ولا تتوقّف.

---

## ١ · المرآةُ الكاملة — آمنةٌ تمامًا، ولا تمسّ البوّابة

**الهدف:** أن يصير كلُّ ما في قوقل موجودًا على جهازك.

> **المجلّدُ الذي تعمل فيه هذه المرحلةُ كلُّها:**
> `warehouse-system-main\.claude\worktrees\upbeat-euclid-143670`
> (هناك تعيش حاوياتُك وأسرارُها اليوم.)

### ١.١ — أدخِل الجديدَ إلى مجلّد الحاويات

```bash
git -C ".claude/worktrees/upbeat-euclid-143670" merge --no-edit claude/tarqiya-77-hybrid
```

> جُرِّب الدمجُ مسبقًا: **نظيفٌ بلا تعارض**.

### ١.٢ — أعِد بناءَ المزامن

```bash
docker compose -f ".claude/worktrees/upbeat-euclid-143670/db/docker-compose.yml" up -d --build sync
```

### ١.٣ — البيّنةُ التي تراها بعينك

```bash
docker logs warehouse-sync --tail 30
```

يجب أن ترى أسماءَ مجموعاتٍ لم تكن تُذكر من قبل (`assets` · `recipes` ·
`bin_locations` …). ثمّ بعد ساعةٍ تقريبًا:

```bash
docker exec warehouse-postgres psql -U warehouse -d warehouse -c "select count(distinct path) as مجموعات, count(*) as مستندات from mirror_docs;"
```

**المنتظَر:** عددُ المجموعات يرتفع تدريجيًّا نحو ٩٣.

> ⚠️ **ولماذا «تدريجيًّا»؟** المجموعاتُ الكبيرةُ تُقرأ كلَّ دقيقتين، والصغيرةُ
> كلَّ ساعة — توزيعٌ مقصودٌ كي لا تُستنزف الحصّة. **الكلفةُ المقيسة:
> ١٧٬٨٠٨ قراءةً يوميًّا من حصّةٍ قدرُها ٥٠٬٠٠٠.**

**وإن أردتَ الرجوع:** `SYNC_FULL_MIRROR=0` في `db/.env` ثمّ أعِد تشغيل المزامن.

## ٢ · تجربةٌ على جهازك — بلا نشرٍ ولا مخاطرة

**الهدف:** أن ترى الهجينَ يعمل بحسابك قبل أن يراه أحد.

### ٢.١ — اسمح لجهازك بطلب الرمز

> ★★★ **والمتغيّرُ يستبدل القائمةَ كلَّها ولا يضيف إليها.** فلو كتبتَ
> `localhost` وحدَه **قطعتَ البوّابةَ المنشورةَ عن الخادم** في اللحظة نفسِها.
> ولهذا لا تُكتب القائمةُ من الذاكرة: تُقرأ من الخادم ثمّ يُضاف إليها.

**اقرأ القائمةَ العاملةَ الآن:**

```bash
docker logs warehouse-auth 2>&1 | grep "العناوين المأذونة" | tail -1
```

ثمّ أضف إلى `db/.env` **في مجلّد الحاويات** سطرًا يحمل **ما طُبع حرفيًّا**،
مفصولًا بفواصل، **وفي آخره** `http://localhost:4321`:

```
AUTH_ALLOWED_ORIGINS=<العنوانان كما طُبعا>,http://localhost:4321
```

ثمّ:

```bash
docker compose -f ".claude/worktrees/upbeat-euclid-143670/db/docker-compose.yml" up -d auth
```

### ٢.٢ — ملفُّ بيئةٍ للبناء المحلّيّ

> ⚠️ **عقبةٌ مقيسة:** لا يوجد ملفُّ `.env` في أيّ مجلّدٍ عندك اليوم — مفاتيحُ
> Firebase تعيش في أسرار GitHub وحدَها. فالبناءُ المحلّيُّ بلا هذه الخطوة
> **يخرج بلا تسجيل دخولٍ أصلًا**، ولا علاقةَ للهجين بذلك.

**من أين تأتي بها:** `console.firebase.google.com` ← مشروع `brandzo-erp-2026`
← ⚙️ إعدادات المشروع ← «تطبيقاتك» ← إعداد SDK. انسخ القيمَ الستّ.

أنشئ ملفًّا اسمه `.env` في جذر شجرة العمل التي ستبني منها:

```
PUBLIC_FIREBASE_API_KEY=...
PUBLIC_FIREBASE_AUTH_DOMAIN=...
PUBLIC_FIREBASE_PROJECT_ID=brandzo-erp-2026
PUBLIC_FIREBASE_STORAGE_BUCKET=...
PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
PUBLIC_FIREBASE_APP_ID=...

PUBLIC_DB_BACKEND=postgres
PUBLIC_PG_API_URL=https://api.warehousehub.com.ly
PUBLIC_PG_AUTH_URL=https://auth.warehousehub.com.ly
```

### ٢.٣ — ابنِ وعايِن

```bash
npm run build && npm run preview
```

> ★ `astro dev` معطوبٌ على هذا الجهاز — **استعمل `preview` دائمًا.**

افتح **العنوانَ الذي يطبعه `preview` نفسُه** (يحمل مسارَ القاعدة، فلا تكتبه من الذاكرة).

### ٢.٤ — البيّنةُ التي تراها بعينك

1. **سجّل الدخولَ بحسابك.** إن لم يفتح، فالعطبُ في مفاتيح Firebase لا في الهجين.
2. افتح **شاشةَ الأصناف**. يجب أن تظهر كما هي تمامًا.
3. افتح أدواتِ المطوّر (F12) ← تبويب **Network** ← اكتب `warehousehub` في المرشّح.
   **المنتظَر:** طلبٌ إلى `auth.warehousehub.com.ly/token` يردّ **٢٠٠**،
   ثمّ طلبٌ إلى `api.warehousehub.com.ly/items?...` يردّ **٢٠٠**.
   ⇒ **هذه هي اللحظةُ التي تثبت أنّ الأصنافَ جاءت من جهازك لا من قوقل.**
4. **جرّب الكتابة:** أنشئ مستندًا أو عدّل صنفًا. يجب أن يعمل كالمعتاد —
   وهو يكتب في Firebase كما كان دائمًا.
5. **جرّب السقوط الآمن:** أوقف الخادم ثمّ حدّث الصفحة:
   ```bash
   docker compose -f ".claude/worktrees/upbeat-euclid-143670/db/docker-compose.yml" stop postgrest
   ```
   **المنتظَر:** البوّابةُ تعمل كما هي — صامتةً، بلا رسالة خطأ. ثمّ أعِده:
   ```bash
   docker compose -f ".claude/worktrees/upbeat-euclid-143670/db/docker-compose.yml" start postgrest
   ```

**لا تمضِ إلى المرحلة ٣ قبل أن تمرّ الخمسُ كلُّها.**

## ٣ · النشرُ الحيّ — وهذه الخطوةُ وحدَها تمسّ البوّابة

### ٣.١ — ضع المفاتيحَ في أسرار المستودع

**مستودعُك على GitHub** ← **Settings** ← **Secrets and
variables** ← **Actions** ← **New repository secret**. ثلاثةٌ واحدًا واحدًا:

| الاسم | القيمة |
|---|---|
| `PUBLIC_DB_BACKEND` | `postgres` |
| `PUBLIC_PG_API_URL` | `https://api.warehousehub.com.ly` |
| `PUBLIC_PG_AUTH_URL` | `https://auth.warehousehub.com.ly` |

> ★★★ **وهذه الأسماءُ مذكورةٌ في `.github/workflows/astro.yml` الآن.** ولم تكن
> مذكورةً قبل 2026-10-20 — ولو وضعتَها يومَها **لخرج البناءُ أخضرَ ولم يصل
> منها حرفٌ إلى الحزمة**، وظننّا أنّها تعمل. ويحرس ذلك اختبارٌ اليوم.

### ٣.٢ — ادمج وارفع

قل لي **«ارفع»** فأدمج الفرعَ في `main` وأدفعه. ولا أفعلها إلّا بأمرك.

### ٣.٣ — البيّنةُ بعد النشر

انتظر اكتمالَ **Actions**، ثمّ افتح البوّابةَ المنشورةَ وكرّر فحصَ **Network**
من الخطوة ٢.٤: طلبُ `api.warehousehub.com.ly` بـ**٢٠٠**.

ثمّ افتح **لوحةَ Firebase ← Firestore ← Usage** بعد يوم: **القراءاتُ يجب أن
تهبط هبوطًا ظاهرًا.**

## ٤ · الرجوع — ثلاثُ دقائق، في أيّ لحظة

| تريد أن توقف | افعل |
|---|---|
| **القراءةَ من جهازك** | احذف سرَّ `PUBLIC_DB_BACKEND` من GitHub ← أعِد تشغيل النشر |
| **بسرعةٍ أكبر** | أضف سرَّ `PUBLIC_DB_HYBRID` بقيمة `off` ← أعِد النشر |
| **المرآةَ الكاملة** | `SYNC_FULL_MIRROR=0` في `db/.env` ← أعِد تشغيل المزامن |

**ولا شيءَ من هذا يفقد بياناتٍ:** الكتابةُ لم تغادر Firebase يومًا.

## ٥ · ما بقي عليك خارج هذا الدليل

1. **٢٥ صفًّا مرفوضًا وتنمو** — ١٨ مستندًا برقمٍ مكرَّر · ٥ مستخدمين · صنفان.
   وهي تُرفض كلَّ دقيقتين إلى الأبد حتّى تُقرَّر.
2. **`AutoStart: false` في Docker Desktop** — فالخادمُ لا يقوم مع الجهاز.
   ⚙️ Settings ← General ← **Start Docker Desktop when you sign in**.
3. **كلمةُ مرورِ المدير العامّ الضعيفة** — تُغيَّر من «نسيت كلمة المرور؟».
