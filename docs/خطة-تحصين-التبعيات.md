# خطة تحصين التبعيّات ‹SEC›

> # 🔑 رمز الاستئناف: **«حصّن»**
>
> اكتب **«حصّن»** في أيّ جلسةٍ جديدة، فتُفتح هذه الخطّة وتُستأنف من حيث توقّفت.
> والحالةُ الحيّة في [`docs/plan/deps-hardening.json`](plan/deps-hardening.json) — تُقرأ بـ`npm run plan:deps`.

> **الحالة:** مسوّدةٌ للاعتماد — **لم تُرقَّ مكتبةٌ واحدة**.
> **السياق:** فعّل المالكُ `Dependabot alerts` في 2026-08-28، **فظهرت ٥٢ ثغرةً كانت مخفيّةً منذ إنشاء المستودع**.
> **القاعدة المُلزِمة:** لا ترقيةَ تُدمج إلّا بعد البوّابة الخضراء كاملةً — ٣٠٧٣ اختبارًا وبناءٌ ناجح.

---

## ٠ · لماذا وُجدت هذه الخطّة

**التنبيهاتُ كانت مُطفأةً منذ إنشاء المستودع.** لا تنبيهَ واحدٌ وصل، ولو كانت
هناك ثغرةٌ حرجةٌ مستغَلّة. وفي اللحظة التي فُعّلت فيها ظهرت **٥٢**.

**ولا تعني أنّ البوّابة مخترَقة.** بوّابتُك **موقعٌ ثابت** بلا خادمٍ يستقبل
طلباتٍ من الإنترنت، وأكثرُ هذه الثغرات تُصيب خوادم. ومعظمُها في **أدوات
البناء** التي تعمل على جهازك ولا تُنشر مع الموقع.

**لكنّ ثلاثًا تصل المتصفّح فعلًا** — وهي وحدها ما يستحقّ العجلة.

## ٢ · الطريقة — موجةٌ موجة، ولا شيءَ يُدمج قبل أن يُثبت

**كلُّ ترقيةٍ تمرّ بهذا حرفيًّا:**

```
npm install <pkg>@<fix>
npm test        # ٣٠٧٣ — لا نقصان
npm run audit   # نظيف
npm run lint    # تحذيرٌ معلومٌ واحدٌ لا أكثر
npm run build   # ١٢٠ صفحة
```

**وما فشل يُردّ فورًا** (`git checkout package*.json && npm install`) ويُسجَّل
في المتتبّع بسبب فشله — **لا يُترك نصفَ مرقًّى**.

### والموجاتُ الثلاث بترتيبٍ مُلزِم

**الموجة ١ — الحرجةُ وأدواتُ البناء (الأقلُّ خطرًا والأعلى قيمة)**
`websocket-driver` · `nanoid` · `js-yaml` · `postcss` · `esbuild` · `@babel/core` ·
`brace-expansion` · `ws` · `adm-zip` · `ip-address`

هذه **لا تُنشر مع الموقع**، فكسرُها يظهر فورًا في البناء ولا يمسّ موظّفًا.

**الموجة ٢ — ما يصل المتصفّح** ★ **تحتاج فحصًا بصريًّا**
`dompurify` (١٠) · `mermaid` (٥) · `svgo` · `sharp`

★ **و`mermaid` ترسم مخطّطات الشاشات** — فبعد ترقيتها **تُفتح شاشةٌ فيها مخطّطٌ
ويُنظر إليه**. اختبارٌ أخضرُ لا يُثبت أنّ الرسمَ ما زال يُرسم.

**الموجة ٣ — النواةُ (الأخطرُ كسرًا)**
`astro` (٦) · `vite` (٤) · `devalue` · `protobufjs` · `@grpc/grpc-js`

★★ **`astro` من ٦ إلى ٧ قفزةٌ كبرى** تُغيّر بنيةَ البناء. **لا تُرقّى مع
غيرها** — وحدَها، وبإعادةِ بناءٍ كاملةٍ وفحصِ عشرِ صفحاتٍ على الأقلّ.

## ٣ · ⛔ الاستثناء الوحيد: `extract-zip`

**بلا إصلاحٍ متاح.** وهي تابعةٌ لـ`puppeteer` (أداةُ تطويرٍ لالتقاط الصور).

**والقرار: تُترك ويُعلَن تركُها** — ولا تُخفى. وتُراجَع حين يصدر إصلاحُها.
وهي في نطاق التطوير فلا تُنشر مع الموقع.

## ٤ · طلباتُ Dependabot العشرة المفتوحة

| الطلبات | ما هي | القرار |
|---|---|---|
| **#١٥–#١٩** | Tailwind · Firebase · Mermaid · Puppeteer · globals | تُفحص في موجتها |
| **#١٠–#١٤** | أدوات GitHub — `checkout 4→7` · `setup-node 4→7` · `github-script 7→9` | ⚠️ **تُغلق** |

**ولماذا تُغلق الخمسُ الأخيرة؟** لأنّها **هي التي تبني الموقعَ وتنشره**،
وقفزةٌ كبرى فيها قد توقف النشر — فتدفع تغييرًا ولا يظهر على الموقع.

★ **وسببُها عيبٌ في إعدادي**: استثنيتُ القفزاتِ الكبرى للمكتبات ونسيتُ
استثناءها لأدوات GitHub. **وإصلاحُ `dependabot.yml` مهمّةُ SEC-000.**
